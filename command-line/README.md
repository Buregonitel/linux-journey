# Linux Journey — Command Line

Completed: September 2026

## Overview

This section covers the fundamentals of working with the Linux shell and command line.

I practiced navigating the filesystem, creating and managing files and directories, inspecting file contents, searching for files, using command documentation, and managing the Bash shell.

## What I learned

The command line is the primary interface for interacting with a Linux system.

I learned how to navigate the filesystem and perform common file-management tasks without relying on a graphical interface.

I also learned how to use the system's built-in documentation to discover command options and understand how commands work.
