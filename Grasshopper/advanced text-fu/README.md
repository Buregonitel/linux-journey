## Key Topics

### Regular Expressions

Regular expressions provide a way to describe patterns in text.

Common concepts include:

* Anchors
* Character sets
* Quantifiers
* Repetition
* Grouping
* Pattern matching

Example:

```text
^user
```

Matches lines beginning with `user`.

### Vim

Vim is a modal terminal text editor.

Its main modes include:

* Normal mode
* Insert mode
* Command-line mode

The workflow is based on combining commands, motions, and operators.

### Emacs

Emacs is another powerful terminal-oriented text editor.

Important concepts include:

* Buffers
* Windows
* Frames
* Point
* Region
* Kill ring
* Built-in help

## What I Learned

The main lesson from Advanced Text-Fu was that text processing is not limited to individual shell commands.

Regular expressions make it possible to describe complex text patterns, while terminal editors provide powerful tools for working directly with files.

I also learned the fundamental workflows of both Vim and Emacs and the different concepts each editor uses for navigation and editing.
